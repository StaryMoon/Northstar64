# Security Policy

## Supported Versions

Security fixes are applied to the latest release and `main` while the project is pre-1.0.

## Reporting

Please use GitHub private vulnerability reporting for memory-safety issues, malformed-image escapes,
or unintended host file/network access. Do not open a public issue before a fix is available.

Northstar64 is an experimental machine model, not a security sandbox. The threat model and known
limits are documented in [docs/threat-model.md](docs/threat-model.md).
