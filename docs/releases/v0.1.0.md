# Northstar64 v0.1.0

The first public baseline establishes a deterministic, inspectable RV64 machine on which the
Northstar kernel can grow.

## Highlights

- RV64I, RV64 word operations, Zicsr, and Zifencei execution
- precise synchronous traps with machine-mode CSR entry and return
- explicit physical bus, sparse RAM, and 16550 UART
- strict, transactional ELF64 RISC-V loading
- deterministic JSONL traces with first-divergence verification
- real `riscv64-unknown-elf-gcc` guest exercised on Northstar64 and QEMU `virt`

## Evidence

- 30 named tests, including fixed-seed property matrices over thousands of instruction cases
- GCC, Clang, and Apple Clang build matrix with warnings treated as errors
- AddressSanitizer and UndefinedBehaviorSanitizer
- CodeQL C++ analysis
- black-box UART, memory, breakpoint, step-limit, and repeated-trace assertions

## Verification Boundary

This release is a single-hart machine-mode baseline. It does not claim RISC-V architecture-suite
compliance, Linux boot, supervisor/user modes, virtual memory, asynchronous interrupts, or M/A/C
extensions. See `ROADMAP.md` for the evidence gates attached to those milestones.

Release archives include SHA-256 checksum files and GitHub build-provenance attestations.
